## Sobre o projeto

O **Gerador de Caça-Palavras** é uma ferramenta web gratuita para criar, personalizar, resolver e imprimir caça-palavras diretamente no navegador. Foi pensado para uso recreativo e educacional, oferecendo recursos tanto para quem deseja montar um desafio individual quanto para quem precisa preparar conjuntos de atividades.

O projeto combina criação de matrizes, posicionamento de palavras, interação com mouse, toque ou teclado e exportação de materiais em PDF. O processamento das palavras e das configurações acontece no próprio navegador, sem exigir cadastro ou uma conta no serviço.

**Acesse:** [eliseuangelos.github.io/caca-palavras](https://eliseuangelos.github.io/caca-palavras/)

## Objetivos do site

- Facilitar a criação de caça-palavras personalizados sem instalar programas.
- Oferecer uma ferramenta acessível para atividades de aprendizagem, vocabulário e entretenimento.
- Permitir a geração de atividades individuais, revistas de passatempo e páginas personalizadas.
- Disponibilizar impressão e exportação em PDF, incluindo gabaritos.
- Funcionar em computadores, tablets e celulares por meio de navegadores modernos.

## Funcionalidades

### 1. Jogo individual

- Criação manual de caça-palavras a partir de uma lista de palavras.
- Geração automática por tema, com possibilidade de personalização.
- Escolha do tamanho da matriz entre opções disponíveis.
- Configuração das direções em que as palavras podem aparecer.
- Seleção das palavras na matriz por mouse, toque e recursos de teclado.
- Cronômetro, acompanhamento do progresso, dicas e embaralhamento.
- Exibição do gabarito, impressão da atividade e exportação em PDF.

### 2. Gerar revista de passatempo

- Criação de **1 a 50 jogos** em uma única operação.
- Montagem de diferentes desafios a partir de um banco de palavras ou tema.
- Identificação sequencial das atividades.
- Exportação em PDF A4, com as atividades organizadas e os respectivos gabaritos reunidos ao final.

### 3. Página personalizada

- Criação de uma atividade com título, subtítulo, identificação, texto, instruções e palavras.
- Organização em página A4 horizontal, com conteúdo textual de um lado e matriz do outro.
- Geração de uma segunda página com as respostas.
- Avisos para situações em que o texto ultrapassa o espaço disponível.

### Experiência de uso

- Interface adaptável a telas menores.
- Tema claro e escuro, com preferência salva no navegador e opção de acompanhar o sistema operacional.
- Indicação de mensagens de erro e sucesso.
- Feedback visual e sonoro ao concluir um jogo, com controle para ativar ou desativar o som.
- Respeito à preferência de movimento reduzido do dispositivo.

## Privacidade e processamento

A ferramenta foi projetada para executar a lógica principal no navegador do visitante. As palavras inseridas para gerar as atividades não precisam ser enviadas a um servidor do projeto, e não há exigência de cadastro para utilizar o gerador. Preferências podem ser mantidas no armazenamento local do próprio navegador.

## Como utilizar

1. Abra o [Gerador de Caça-Palavras](https://eliseuangelos.github.io/caca-palavras/).
2. Escolha o modo de criação adequado: jogo individual, revista ou página personalizada.
3. Informe as palavras e os parâmetros solicitados.
4. Gere a atividade e confira o resultado.
5. Jogue no navegador ou utilize as opções de impressão e PDF.

## Execução local

O projeto pode ser obtido pelo Git:

```bash
git clone https://github.com/eliseuangelos/caca-palavras.git
cd caca-palavras
python3 -m http.server 8000
```

Depois, abra `http://localhost:8000/` no navegador. A estrutura atual do repositório inclui arquivos da aplicação, recursos visuais e documentação. Para publicar alterações, mantenha os caminhos relativos utilizados pelo site e confira o resultado no GitHub Pages.
