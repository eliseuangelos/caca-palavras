# 🧩 Gerador e Jogador de Caça-Palavras Online

Um aplicativo web interativo, moderno e totalmente gratuito desenvolvido em **HTML5, CSS3 e JavaScript (Vanilla)** que permite aos usuários criarem, jogarem e imprimirem seus próprios **Caça-Palavras personalizados**.

🌐 **Acesse o projeto online:** [https://eliseuangelos.github.io/caca-palavras/]

---

## ✨ Principais Funcionalidades

- **Personalização Completa:** Insira suas próprias palavras e escolha o título e subtítulo do jogo.
- **Tamanhos de Grade Flexíveis:** Escolha entre tamanhos de grade personalizados (14x14, 16x16 ou 18x18) para diferentes níveis de dificuldade.
- **Interatividade Total (Mobile e Desktop):** Selecione as palavras arrastando o mouse ou deslizando o dedo na tela (suporte completo a touch screens).
- **Modo Impressão Otimizado:** Imprima o jogo e as respostas de forma limpa, sem elementos desnecessários da tela, perfeito para escolas, passatempos ou eventos.
- **Ferramenta de Ajuda ("Revelar"):** Encontre instantaneamente uma palavra caso fique preso, sem sistema de pontuação estressante.
- **Rodapé Dinâmico:** Acompanha o link de origem/compartilhamento automático como marca d'água.
